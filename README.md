
# Commit Chronicles

Commit Chronicles is an engineering intelligence platform that
analyzes Git repository history to identify code-risk patterns
and predict potentially bug-prone files using machine learning.

## Planned capabilities

- Git repository ingestion
- Commit and contributor analytics
- File-level risk analysis and heatmaps
- Machine learning-based bug-proneness predictions
- Historical risk trends and reports
- Scheduled repository scans
- CI/CD integration

## Architecture

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL with Prisma
- ML service: Python and scikit-learn
- DevOps: Docker, GitHub Actions, Kubernetes

## Project structure

- `apps/web` — frontend application
- `apps/api` — backend API
- `services/ml` — machine learning service
- `docs` — technical documentation
- `scripts` — development scripts
